# Automation page image studies

The service-card thumbnails are local copies of public preview images from the Framer Marketplace templates directory:

- [Framer Marketplace templates](https://www.framer.com/marketplace/templates/)
- Vexoo, GreenKeeper, YUYA, Billie, AdScale, Stuffmade, Strategic Brand Designer and Brog previews

They are used as visual studies inside the local RYCODE service page. The page does not load them from the remote CDN at runtime.
