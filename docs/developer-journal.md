# مجلهٔ برنامه‌نویسی رایکد

بلاگ بخشی از پروژهٔ موجود Next.js App Router است. `/blog` و `/blog/[slug]` از همان PostgreSQL، Prisma و محتوای Tiptap پنل مدیریت استفاده می‌کنند. فارسی زبان اصلی است؛ مسیرهای انگلیسی `/en/blog` و `/en/blog/[slug]` تنها ترجمه‌های تأییدشده را نشان می‌دهند.

## اضافه کردن مقاله

در `/admin`، بخش محتوا، «مقاله» را انتخاب کنید. اسلاگ خوانا، عنوان، خلاصه، دسته‌بندی، برچسب‌ها، تصویر شاخص و متن جایگزین را پر کنید. دسته‌بندی‌های بلاگ خودکار از مقاله‌های قابل‌مشاهده ساخته می‌شوند. تیترهای ۲ و ۳ فهرست مطالب را می‌سازند. برای کد، دکمهٔ «کد» و سپس زبان آن را انتخاب کنید؛ Tab تورفتگی دو فاصله‌ای ایجاد می‌کند. جدول و افزودن سطر/ستون در همان ویرایشگر موجود است.

گزینهٔ «مقالهٔ منتخب بلاگ» مقاله را در بخش منتخب‌ها قرار می‌دهد؛ ترتیب نمایش برای اولویت این بخش است. حداکثر سه منتخب نمایش داده می‌شود. زمان مطالعه از متن و خطوط کد محاسبه می‌شود و نیاز به ورود دستی ندارد. ترجمهٔ فارسی باید تأیید شود؛ سپس وضعیت انتشار یا انتشار زمان‌بندی‌شده را انتخاب کنید. پیش‌نمایش خصوصی از همین طراحی استفاده می‌کند و وارد سئو نمی‌شود.

محتوای نمونه با گزینهٔ مستقل `sample` مشخص است؛ کارت و مقاله برچسب دارند و حتی با خاموش کردن دستی noIndex، در DTO و sitemap ایندکس‌پذیر نمی‌شوند. برای تبدیل نمونه به مقالهٔ واقعی، متن را تکمیل و بررسی کنید، برچسب نمونه را بردارید، اطلاعات سئو را اصلاح کنید و noIndex را طبق تصمیم انتشار تنظیم کنید. هیچ نمونه‌ای با اجرای عادی seed تولید نمی‌شود.

## راه‌اندازی و نمونه‌ها

```sh
npm ci
npm run db:generate
npm run db:migrate
# اختیاری، صرفاً برای مشاهدهٔ رابط با هشت مقالهٔ نمونهٔ فارسی:
npm run db:seed-blog
npm run dev
```

Seed نمونه‌ها تکرارپذیر است و هیچ مقالهٔ موجود یا ویرایش مدیر را بازنویسی نمی‌کند. دادهٔ نمونهٔ اولیه در `src/content/journal-samples.ts` و کاورها SVGهای محلی `public/brand/journal/` هستند؛ صفحه‌ها در زمان اجرا داده را فقط از CMS می‌گیرند.

## رفتار و محدودیت‌ها

- جست‌وجوی سمت سرور در عنوان، خلاصه و برچسب، همراه دسته‌بندی و صفحه‌بندی ۱۲تایی؛ لینک هر فیلتر و صفحه قابل اشتراک است. فیلترها انتشار، زمان‌بندی و تأیید ترجمه را رعایت می‌کنند.
- highlight.js روی سرور فقط دستور زبان‌های پشتیبانی‌شده را بارگذاری می‌کند. زبان ناشناخته به شکل متن ساده و escape شده باقی می‌ماند. فاصله و تب حفظ می‌شود؛ کد و ترمینال LTR و متن فارسی RTL است.
- کپی کد و لینک از Clipboard API استفاده می‌کنند؛ در localhost یا HTTPS کار می‌کنند و شکست را به کاربر اعلام می‌کنند.
- حالت تاریک بلاگ از سوییچ تم موجود پیروی می‌کند؛ صفحات دیگر بازطراحی نشده‌اند.
- JSON-LD مقاله و Breadcrumb برای مقالهٔ واقعی، OG اختصاصی، canonical و ترجمه‌های تأییدشده حفظ شده‌اند. نمونه‌ها noindex هستند و JSON-LD انتشار واقعی ندارند.
- کلیدهای `featured` و `sample` با migration افزایشی اضافه شده‌اند؛ پیش از اجرای نسخهٔ جدید روی Ubuntu، workflow موجود باید `prisma migrate deploy` را اجرا کند.

## بررسی‌ها

`npm run lint`، `npm run typecheck`، `npm test` و `npm run build` بررسی‌های کد هستند. `npm run test:local` تست PostgreSQL را روی دیتابیس جداگانهٔ `rycode_test…` اجرا می‌کند؛ تست‌ها به دیتابیس اصلی اجازهٔ حذف داده نمی‌دهند. جست‌وجو، ترکیب فیلتر، صفحه‌بندی، محتوای پیش‌نویس، کپی، TOC، پیشرفت مطالعه و نمایش موبایل باید در مرورگر نیز بررسی شوند.
